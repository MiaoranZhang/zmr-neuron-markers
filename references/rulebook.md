# 逐类型鉴定规则 v1.1

本规则册覆盖现有 37 个审阅面板，不宣称覆盖成人脑所有类型。先看[谱系与递质规则](rules-identity.md)，再按实际脑区看[区域亚型与程序规则](rules-contextual.md)。机器可读内容在 `assets/rules/identity.json` 和 `assets/rules/contextual.json`，与旧版基因溯源表通过面板 ID 关联。

这些是原创编辑的、尚未经过独立队列准确率评估的审阅规则。来源基因事实、作者的组合、我们新增的审阅条件分别记录；规则编写完整、程序测试通过不等于生物学已验证。本版不提供未经评估的基因补救组合，不把 High 写成 95% 概率。

合计 37 个面板，对应 26 条身份规则和 11 条程序规则，并非 37 种相互排他的细胞类型。每条都包含适用范围、父级、核心路径、辅助、冲突、High 条件、置信上限、降级与来源。尚未覆盖的精细类型不能强行分入最接近的已有规则。

## 鉴定对象与置信度

一次评估只针对一个对象（细胞或簇）和一个标签层级：major、transmitter、subtype 或 program。分别保存大类、递质、亚型置信度；程序的 High 只说明相应表达程序可靠，不能直接变成细胞类型、功能释放能力或 PD 易损性结论。

簇级证据不能原样赋给所有成员细胞。簇的多基因信号应主要来自相容的细胞群，而不是不同小群各提供一个基因。对稀疏单细胞，若仅通过簇背景或参考预测支持，记录推断来源及不确定性；不要伪造该细胞的 marker 检出。

| 等级 | 判定标准 |
| --- | --- |
| High | 至少一条预定义核心路径满足；四个公共门槛和该规则全部附加检查均有通过依据；父层级满足；没有未解决强冲突；审核人和日期完整；未超过规则允许的上限。 |
| Moderate | 有部分核心审阅证据，但关键证据、竞争类型区分或附加检查尚不完整。完整核心路径满足时可显示具体候选；仅部分核心时只表示证据不完整，不自动建议具体类型。 |
| Low/Uncertain | 只有泛化辅助信号、无法支持核心方向、质量不合格或存在未解决强冲突；返回证据支持的父层级或 Unknown。 |
| NotApplicable | 物种、发育阶段或实际脑区不符合规则；不在错误范围内强行计算置信度。 |

公共门槛：

1. **适用性 applicability**：物种、阶段、脑区和父身份匹配；来源标签的粒度与待判标签一致。`regions=all` 是宽泛筛查范围，不代表基因普遍特异。
2. **表达质量 data_quality**：基因 ID、可测性、RNA 表达层、测序深度及 ambient/doublet 风险已评估；未检出和未测量分别记录。
3. **区分能力 discrimination**：核心组合在当前对象中相容，并能区分规则列出的主要竞争程序；记录表达比例、效应量、同细胞关系和对照类型。只有总表达高或模块分数高不能通过。
4. **冲突审阅 conflict_review**：竞争谱系的成套表达没有留下未解决解释。单个冲突基因不构成自动否决；负 marker 的零 counts 不构成通过证据。

每个 pass 必须关联可查看的证据记录，并由操作者承担审阅判断。工具只检查填写的一致性，不会核实证据附件的真实性，也不会从表达矩阵自动生成 pass。阈值应针对实际平台、深度、比较对象预先设定并记录，不能为了获得预期身份反复修改。

检查器对 Low 只输出 `Unknown/Uncertain`，对 NotApplicable 不建议生物学标签。具体规则里的父级回退名称是人工处理指引，不代表父级已被此检查器证明；实际保留父级前要确认它仍有有效证据，尤其不能在谱系冲突或质量失败后自动继承。

检查器的 `review_grade` 是审阅材料完整性等级，不能直接复制成细胞身份置信度。尤其部分核心的 Moderate 并不说明该类型已经获得中等强度的特异支持：例如仅 DDC 不自动命名 DA/NE/ADR/5-HT 候选，仅 SLC32A1 不自动命名甘氨酸能候选，缺 PNMT 的 NE 核心不自动命名 ADR 候选。工具在这些情况下只提示“该层级未定、核心证据不完整”，人工可依照具体规则另行记录更粗的候选或父级。

## 核心、辅助与冲突集合

- **核心路径 core_routes**：多个功能互补或具有分类区分力的证据组合。JSON 的外层 `all_of` 要求各证据组成立，内层数组表示该组可接受的基因替代项；多条 route 是替代路径，不是必须全部成立。规则是审阅层的支持逻辑，不能直接将原始 `UMI>0` 当作 supported。
- **辅助集合 supporting**：增加一致性、脑区或父层级支持。它不能仅凭数量、总分或“也出现在数据库”替代缺失核心。辅助基因也不是独立验证。
- **冲突集合 conflicts**：提示需要比较的其他程序。保留原作者阴性极性，但生物学共递质、共享标志和环境 RNA 需要分别核验，不机械互斥。

例如，GABA 的 GAD1 与 GAD2 作者规则是替代路径，SLC6A5 在这两条作者规则中是负标志；并非将甘氨酸阳性 marker 混进 GABA 核心。SLC32A1 是两种抑制性递质共享的装载证据。

## 缺失与替代

| 情况 | 处理 |
| --- | --- |
| 某核心基因未检出，但另一条已登记核心路径满足 | 可以继续评估，不必强制所有列出的基因同时检出；仍须通过四门槛。 |
| 只有部分核心及辅助支持 | 只记录部分证据和该层级未定；更粗候选或父级需另行人工核验。不得把共享核心或辅助信号自动转换为具体类型候选，也不得算成未检出的核心基因。 |
| 核心基因未测量 | 记录 not_assayed；审阅其它已登记核心路径是否有足够可测证据。无路径可评估时保留父类，不能补零。 |
| 核心可测却在候选群体中整体缺乏 | 重新比较身份与质量，不能默认全是 dropout，也不能靠大量辅助基因覆盖反证。 |
| 存在强冲突且未解决 | Low/Uncertain，按冲突层级回退；不自动删除细胞，不自动称双细胞。 |

本版全部 `rescue_routes=[]`：没有新补救规则被证明在匹配人群、脑区和平台中足够可靠。作者已使用的替代核心路径与新增“缺失补救”不是同一概念。今后引入 rescue，至少记录替代基因组合、适用缺失模式、参考版本、与核心方案独立的评估对象、错误类型和拒绝条件，再作版本升级。不能仅凭单次案例成功就开放通用替代。

## 复现与验证分别记录

`donor_replication` 描述供者间复现；`independent_validation` 描述独立参考、留出样本或其它实验支持。这两项不通过加分直接把身份升级为 High，也不因稀有类型只有一个供者就自动判其身份错误。

同一研究派生的规则、表和参考模型属于同一 evidence family。用来定名的辅助基因、原作者标签或参考预测不能再次算作独立验证。比较跨供者一致性时报告可评估供者数、支持方向、检测深度和异质性，不只统计 pooled cells。

## 使用审阅检查工具

```text
python scripts/review_rules.py --validate
python scripts/review_rules.py --template da-core
python scripts/review_rules.py --evidence YOUR_REVIEW.json
```

模板初始状态均为 unknown/undetermined，需结合真实未整合表达填写。输出是审阅材料所支持的等级和缺口，不会修改细胞对象、给全矩阵自动贴标签或上传数据。输入/输出契约及字段见[数据约定](data-contract.md)。

## 本版采纳的科学修订

- 神经肽或受体的生化功能不能决定它是否有身份鉴定价值。HCRT/PMCH 在匹配的下丘脑背景和完整表达证据下可以支持类型鉴定；本包现有单基因肽面板只评估程序，完整下丘脑类型判定需补充对应参考，不能自动升级。[人类 HYPOMAP](https://www.nature.com/articles/s41586-024-08504-8)、[人类下丘脑发育与成人研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC10631741/)
- PPP1R1B 不证明 DA 合成身份，也不等同于通路激活状态；可作为匹配解剖背景中的辅助身份线索。TPH2 优先用于成人脑 5-HT 程序，TPH1 检出仅触发复核，不自动判污染或改名。[人脑 PPP1R1B 研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC4571731/)、[TPH1/TPH2 人脑研究](https://pubmed.ncbi.nlm.nih.gov/16023677/)
- PVALB/SST/VIP/LAMP5 的区域限制针对分类定义，不意味着基因只存在于皮层。SOX6/CALB1 等 DA 相关程序不直接赋予易损/抗性结论；TMEM200A 不作为一个唯一 Kamath 亚型的同义词。[Kamath 2022](https://doi.org/10.1038/s41593-022-01061-1)
- NeuN 蛋白免疫阴性与人类 RBFOX3 RNA 未检出应分开记录。高置信度规则不把任何单个零 counts 当作可靠的生物学排除。[NeuN 原始研究](https://pubmed.ncbi.nlm.nih.gov/1483388/)、[核与细胞转录本比较](https://pmc.ncbi.nlm.nih.gov/articles/PMC6306246/)

# 成人脑神经元分层鉴定

## 输入审计

确认人类/动物、成年/发育、实际脑区、scRNA/snRNA、平台、counts/标准化表达、QC与供者字段。原作者初筛身份独立保存；参考供者和分析供者可能重叠时记录，不称独立验证。先审计 marker 是否可测，以及 Ensembl 版本、symbol 歧义、重复映射。不能用缺失基因补零表达。

## 分层判断

1. **谱系**：神经元多基因背景与胶质/血管/免疫排除程序。RBFOX3 不覆盖所有神经元；TUBB3、SNAP25 等也不能单独定义成熟神经元。髓鞘转录本散在存在不证明少突身份，要看一致的谱系程序、深度和环境 RNA 证据。
2. **递质**：合成、囊泡装载/转运与神经元背景共同支持；保留来源本来的组合与替代路径。GAD 或 SLC17 单基因阳性只能提出候选；TH 不单独定义 DA，DDC/SLC18A2 也被其他单胺程序共享。受体表示接收信号，不自动证明该递质的分泌身份。
3. **区域亚型**：仅在脑区、父层级和完整参考证据支持时评估。PVALB/SST/VIP 在皮层的类别含义不能直接移植为中脑类别；DRD1/DRD2 受体单基因不定义 MSN。小脑/海马/皮层规则与中脑默认分开。
4. **DA 子分支**：先确认可靠 DA，再比较 Kamath SOX6/CALB1 及相关程序。AGTR1 等是特定研究的亚型证据，不从单个基因推断解剖位置、PD 易损性或疾病差异。
5. **程序而非身份**：神经肽、成熟度、应激、细胞周期及髓鞘背景分别描述。HCRT/PMCH 等共现需要逐细胞、脑区与技术核验，不通过一个肽基因建立新类型。

## marker 证据

使用未整合表达绘制 DotPlot/FeaturePlot；报告群体内外检测比例、差值、log2FC、可测细胞/供者数。区分群体检出、同细胞组合与跨供者复现。单核低表达基因可能掉落；不能机械采用统一检测率或固定概率门槛。

若需要评分，用匹配物种/脑区的正负面板，明确标准化方式、背景基因和测量覆盖率；分值是支持度不是校准身份概率。不要对未整合表达的源数据反复补值以得到期望 marker。预先定义少量比较及失败/拒绝条件。

不要将事后聚类 marker 的细胞级 P 值作为“簇是真实类型”的证据。疾病 DE/丰度是另一个任务，需要供者为重复单位；本技能不把 marker 排名转换为疾病结论。

## 匹配参考

优先检查 Siletti 成人全脑的对应脑区和 Allen HMBA 人类基底节/黑质参考。参考下载可能很大，先查看元数据/统计及基因匹配，再决定完整矩阵是否必要。保留参考版本、基因空间、输入标准化和方法参数。不要把 Harmony/CCA embedding 当作 RNA 表达传给分类器。

可评估 Allen `cell_type_mapper` 的本地层级映射，或在现有生态内采用适用的参考方法。无需同时跑所有算法。模型存在的标签不代表 query 一定存在；保存候选、分数、拒绝/冲突信号，不把模型最高分自动命名为已证实身份。大类一致、精细层级冲突时降级到父层级。

Siletti 作者规则、Siletti 表、基于同一 Siletti 图谱训练的预测和由其整理的 marker 不是多个独立来源。依据 evidence_family 去重，并报告共享证据。

## 混合／未定簇

区分：不同身份细胞混在同一簇；同一个细胞支持多递质程序；低深度无法判定；双细胞/ambient RNA/供者批次解释。UMAP 重叠或簇中两种 marker 各自出现不区分这些情形。

需要子聚类时从该子分支未整合表达/原始 counts 重新选择特征并降维，不对旧整合坐标再次当作表达校正；这是后续分析，需属于用户当前授权。全局展示更新本身不授权重分析。

## 置信度和交付

- 神经元大类可靠，但递质不足：`Neuron: transmitter unresolved`。
- 有多种递质证据但细胞级关系尚不清楚：`Neuron: mixed/unresolved transmitter`，不称已确定的共递质类型。
- 谱系本身不一致：`Unknown/Uncertain`，记录候选、技术替代解释及冲突。
- 区域亚型依据不足：只保留父类或“基因程序富集”的描述。

可使用 High/Moderate/Low 描述等级，但必须写明依据，且大类、递质、亚型分别评估。交付字段参见 data-contract.md。保留原对象和历史注释；该技能不默认删除任何未定细胞。
